Universal Links Tester

ตรวจไฟล์ .well-known ของ iOS Universal Links และ Android App Links แล้วดูว่า Apple CDN กับ Google ดึงไฟล์เวอร์ชันล่าสุดไปแล้วหรือยัง

ใส่โดเมนหรือ URL ก็ได้ เช่น example.com หรือ https://www.example.com/path

เบื้องหลังการเปิดลิงก์

ดูว่า request วิ่งไปที่ไหนบ้าง ตั้งแต่ติดตั้งแอปจนผู้ใช้แตะลิงก์

สิ่งที่ตรวจ

iOS · ไฟล์บนเว็บ
https://<domain>/.well-known/apple-app-site-association: ต้องได้ 200 โดยไม่ redirect, เป็น JSON ที่ถูกต้อง, ขนาดไม่เกิน 128 KB และมี applinks
iOS · Apple CDN
https://app-site-association.cdn-apple.com/a/v1/<domain>: อุปกรณ์ iOS ดึงไฟล์จากที่นี่ ไม่ได้ดึงจากเว็บตรงๆ จึงต้องเช็คว่าเนื้อหาตรงกับไฟล์บนเว็บแล้วหรือยัง
Android · ไฟล์บนเว็บ
https://<domain>/.well-known/assetlinks.json: ต้องได้ 200 โดยไม่ redirect, เป็น application/json และมี statement handle_all_urls
Android · Google API
digitalassetlinks.googleapis.com/v1/statements:list: ดูว่า Google อ่านไฟล์ได้และเห็น package / fingerprint ตรงกับไฟล์บนเว็บ
