ตรวจสอบไฟล์ .well-known และสถานะ Propagated CDN

วิเคราะห์ไฟล์ต้นทางบนเว็บ เทียบกับข้อมูลที่แคชอยู่บน Apple CDN และ Google Digital Asset Links แบบเรียลไทม์ พร้อมจำลองการจับคู่ URL Path

https:// /
ตัวอย่างทดสอบ:

1. Origin Server (/.well-known/*)

ไฟล์ต้นทางบนเซิร์ฟเวอร์ต้องตอบกลับด้วย HTTP 200 OK โดยตรง ห้ามติด Redirect (301/302) ต้องมี Content-Type: application/json และสำหรับ iOS ขนาดไฟล์ต้องไม่เกิน 128 KB

2. Apple AASA CDN Propagation

อุปกรณ์ iOS ไม่ได้ดึงไฟล์จากเว็บของคุณโดยตรง แต่ดึงผ่าน app-site-association.cdn-apple.com หากคุณเพิ่งอัปเดตไฟล์ ต้องรอให้แคชบน Apple CDN หมดอายุ (ดูได้จากแถบ Cache TTL ด้านบน)

3. Google Digital Asset Links

Android ตรวจสอบสิทธิ์การเปิดลิงก์ผ่าน digitalassetlinks.googleapis.com โดยเช็คว่า package_name และ sha256_cert_fingerprints ตรงกับไฟล์ assetlinks.json บนเว็บ
